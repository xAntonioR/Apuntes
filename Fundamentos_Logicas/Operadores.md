# Operadores <br>
 * Los operadores son símbolos especiales que nos permiten realizar operaciones en variables y valores. Python proporciona diferentes tipos de operadores para realizar operaciones aritméticas, comparaciones y operaciones lógicas:
## Aritméticos

 * Los operadores aritméticos se utilizan para realizar operaciones matemáticas básicas. Los principales operadores aritméticos en Python son:
   * Suma (+): suma dos valores.
   * Resta (-): Resta el segundo valor del primero.
   * Multiplicación (+): multiplica dos valores.
4. División (/): divide el primer valor por el segundo y devuelve el resultado en tipo de dato numérico flotante (float).
5. División entera (//): divide el primer valor por el segundo y devuelve el resultado en tipo de dato numérico entero (int) descartándose la parte decimal.
6. Módulo (%): devuelve el resto de la división entre el primer valor y el segundo.
7. Exponencianión (**): eleva el primer valor a la potencia del segundo.
