## ¿Para qué sirve Algoritmo? 

* Es una serie de pasos escritos en lenguaje de alto nivel que son interpretados y/o compilados a lenguaje de maquina que sirven para que el computador pueda reconocerlos y seguirlos.
  #### Ejemplo:
```PY
    def preparar_cafe():
    print("1. Encender máquina")
    
    # Condición: ¿agua?
    hay_agua = input("¿Hay agua? (s/n): ").strip().lower()
    if hay_agua == 'n':
        print("-> Llenar depósito")
        
    # Condición: ¿cápsulas?
    hay_capsulas = input("¿Hay cápsulas? (s/n): ").strip().lower()
    if hay_capsulas == 'n':
        print("-> Hacer pedido")
        
    print("-> Introducir y ON")

    if __name__ == "__main__":
    preparar_cafe()
```

## ¿Cómo Comunicarnos con el Computador?
*Para esto necesitamos la ayuda de traductores, encargados de pasar el lenguaje de alto nivel comprensible para el programador a lenguaje de máquina ( 0,1).
#### Compiladores:
*Lee el código fuente escrito en un determinado lenguaje de programación, lo interpreta, comprueba la sintaxis y traduce toda la seria de instrucciones a lenguaje de maquina generando un archivo ejecutable.
